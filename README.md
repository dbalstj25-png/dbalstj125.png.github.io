# 나의 개인 웹사이트

기존 `index.html`의 기본 문구를 바탕으로 만든 반응형 개인 소개 웹사이트입니다. 소개, 프로젝트, 연락처가 각각 독립된 섹션으로 나뉘어 있어 원하는 부분만 쉽게 수정할 수 있습니다.

## 사이트 내용 수정하기

- **소개 문구, 프로젝트 이름·설명, 이메일 주소**: `index.html`에서 해당 문장을 찾아 바꾸세요.
- **색상, 글꼴 크기, 여백, 모바일 디자인**: `style.css`를 수정하세요. 파일 맨 위의 `:root`에 있는 `--paper`, `--ink`, `--accent` 값으로 기본 색상을 바꿀 수 있습니다.
- **메뉴 동작, 화면 하단 연도**: `script.js`에서 수정하세요.
- **프로젝트 추가**: `index.html`의 `<article class="project-card ...">` 블록 하나를 복사해 `<div class="project-grid">` 안에 붙여넣고 내용을 바꾸세요.

수정 후 파일을 저장하고 GitHub에 올리면 GitHub Pages가 사이트를 업데이트합니다. 사이트 주소와 배포 상태는 저장소의 **Settings → Pages**에서 확인할 수 있습니다.

## 방문자 수 측정하기 (GoatCounter)

방문자 수를 집계하려면 무료 웹 분석 서비스인 GoatCounter에 사이트를 등록해야 합니다. 계정을 만들면 제공되는 코드(예: `내코드.goatcounter.com`)를 사용하세요.

1. [GoatCounter](https://www.goatcounter.com/)에서 계정을 만들고 사이트 코드를 정합니다.
2. `index.html` 맨 아래에 있는 GoatCounter 코드 예시의 HTML 주석(`<!--`와 `-->`)을 제거합니다.
3. `YOUR-CODE`를 계정에서 만든 실제 사이트 코드로 바꿉니다. 예: `https://내코드.goatcounter.com/count`
4. 변경 사항을 GitHub에 올리고 배포된 사이트를 방문합니다. 이후 통계는 GoatCounter 대시보드에서 확인할 수 있습니다.

계정을 만��고 코드를 설정하기 전까지는 방문자 통계가 수집되지 않습니다. 개인 식별 정보를 직접 수집하지 않는 분석 서비스를 선택하고, 사이트에 개인정보 처리방침 또는 분석 사용 안내를 표시하는 것도 고려하세요.
